Inventory Page Implementation Guide

Converting Products Page → Full Inventory System with Stock Tracking

1

What We Are Building

The current "Products" page will be upgraded into a comprehensive Inventory Management page. Key features include:

  • Stock Tracking: The product form will now ask for 'Quantity' (stock level) in addition to Name, Price, and Unit.
  • Visual Indicators: The inventory table will display current stock with color-coded alerts (e.g., red for low stock).
  • Automated Deduction: When a user creates and saves an invoice, the quantities of the purchased items will automatically be deducted from the inventory.
  • Stock Validation: If a user tries to invoice an item with insufficient stock, the system will prevent the save and warn the user.
2

Database Changes (Step 1)

We need to modify the existing products table in PostgreSQL to include a quantity column.

-- Run this in your PostgreSQL database (psql or pgAdmin)
ALTER TABLE products ADD COLUMN quantity INTEGER NOT NULL DEFAULT 0;

Note: This command safely adds the quantity column. All existing products will default to a stock quantity of 0.

Complete Updated index.js (Save Invoice Route)

This is the critical part: validating stock and deducting quantities when an invoice is saved.

app.post("/invoices", async (req, res) => {
  const client = await pool.connect();
  try {
    const { customer_id, invoice_date, subtotal, gst, grand_total, items } = req.body;

    await client.query("BEGIN");

    // ✅ STEP 1: Validate stock for all items FIRST
    for (const item of items) {
      const stockResult = await client.query(
        "SELECT quantity, name FROM products WHERE id = $1",
        [item.product_id]
      );
      const product = stockResult.rows[0];
      if (!product || product.quantity < item.qty) {
        await client.query("ROLLBACK");
        return res.status(400).json({
          error: `Insufficient stock for "${product?.name || 'Unknown'}". 
                  Available: ${product?.quantity ?? 0}, Requested: ${item.qty}`
        });
      }
    }

    // ✅ STEP 2: Insert invoice
    const invoiceResult = await client.query(
      `INSERT INTO invoices (customer_id, invoice_date, subtotal, gst, grand_total)
       VALUES ($1, $2, $3, $4, $5) RETURNING *`,
      [customer_id, invoice_date, subtotal, gst, grand_total]
    );
    const invoice = invoiceResult.rows[0];

    // ✅ STEP 3: Insert invoice items
    for (const item of items) {
      await client.query(
        `INSERT INTO invoice_items (invoice_id, product_id, product_name, price, qty, unit, total)
         VALUES ($1, $2, $3, $4, $5, $6, $7)`,
        [invoice.id, item.product_id, item.product_name, item.price, item.qty, item.unit, item.total]
      );
    }

    // ✅ STEP 4: Deduct stock from inventory
    for (const item of items) {
      await client.query(
        `UPDATE products SET quantity = quantity - $1 WHERE id = $2`,
        [item.qty, item.product_id]
      );
    }

    await client.query("COMMIT");
    res.json(invoice);
  } catch (error) {
    await client.query("ROLLBACK");
    console.error("Save invoice error:", error);
    res.status(500).json({ error: error.message });
  } finally {
    client.release();
  }
});
